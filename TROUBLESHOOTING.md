# Устранение неполадок VoiceDrop

## Проблема: Приложение автоматически закрывается

Если VoiceDrop неожиданно закрывается, особенно при запуске других Python проектов (PyCharm, VS Code и т.д.), это может быть вызвано несколькими причинами:

### Возможные причины:

1. **Другие программы убивают Python процессы**
   - Скрипты автоматизации
   - Task Scheduler задачи
   - Batch-файлы, которые завершают все Python процессы

2. **IDE управляют Python процессами**
   - PyCharm может иметь настройки управления процессами
   - Visual Studio Code с расширениями Python
   - Другие IDE

3. **Антивирус или защитное ПО**
   - Ложные срабатывания
   - Ограничения на фоновые процессы

4. **Системные ограничения**
   - Ограничения памяти
   - Политики безопасности Windows

### Диагностика

#### 1. Проверьте логи приложения

```bash
# Откройте файл voicedrop.log в папке приложения
notepad voicedrop.log
```

Лог-файл содержит подробную информацию о:
- Запуске приложения
- Создании mutex (защита от дублирования)
- Всех операциях
- Ошибках и предупреждениях
- Сигналах завершения

#### 2. Запустите диагностику Python процессов

Запустите `diagnose.bat`, чтобы отслеживать все Python процессы в системе:

```bash
diagnose.bat
```

Этот инструмент:
- Покажет все запущенные Python процессы
- Обнаружит VoiceDrop
- Предупредит, если какой-либо Python процесс будет завершен
- Поможет выяснить, что убивает процессы

**Инструкция:**
1. Запустите VoiceDrop через `run.bat`
2. Запустите `diagnose.bat` в отдельном окне
3. Запустите PyCharm или другой Python проект
4. Наблюдайте за выводом diagnose.bat

Если VoiceDrop закрывается, diagnose.bat покажет это и предложит возможные причины.

#### 3. Используйте Watchdog (автоматический перезапуск)

Если вы хотите, чтобы VoiceDrop автоматически перезапускался при неожиданном закрытии:

```bash
run_with_watchdog.bat
```

Watchdog будет:
- Следить за процессом VoiceDrop
- Автоматически перезапускать его при сбое
- Логировать все перезапуски в `watchdog.log`
- Считать количество перезапусков

**Примечание:** Если приложение перезапускается слишком часто (5+ раз), проверьте логи на наличие серьезных ошибок.

### Решения

#### Решение 1: Проверьте Task Scheduler

```powershell
# Откройте Task Scheduler
taskschd.msc
```

Ищите задачи, которые могут завершать Python процессы.

#### Решение 2: Проверьте автозапуск скрипты

Проверьте папки автозапуска:
- `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup`

Ищите .bat или .vbs файлы, которые могут управлять процессами.

#### Решение 3: Настройте PyCharm

В PyCharm:
1. Settings → Tools → Python Integrated Tools
2. Проверьте настройки управления процессами
3. Отключите автоматическое завершение процессов

#### Решение 4: Исключения в антивирусе

Добавьте VoiceDrop в исключения вашего антивируса:
- Папка: `C:\Tools\VoiceDrop`
- Процесс: `pythonw.exe` (из папки `.venv\Scripts\`)

#### Решение 5: Уникальный mutex

В новой версии VoiceDrop использует уникальный mutex на основе пути установки:
```
Global\VoiceDrop_C_Tools_VoiceDrop_main.py
```

Это предотвращает конфликты с другими Python приложениями.

### Улучшения в новой версии

1. **Защищенный mutex**
   - Mutex хранится как глобальная переменная
   - Защита от сборщика мусора
   - Автоматическое освобождение при выходе

2. **Расширенное логирование**
   - Все события записываются в `voicedrop.log`
   - Информация о сигналах завершения
   - Подробности об ошибках

3. **Обработка сигналов**
   - Graceful shutdown при SIGTERM/SIGINT
   - Гарантированное размьютирование аудио

4. **Диагностические инструменты**
   - `diagnose.bat` - мониторинг процессов
   - `watchdog.py` - автоматический перезапуск
   - Подробные логи

### Поддержка

Если проблема сохраняется:

1. Соберите информацию:
   - `voicedrop.log`
   - `watchdog.log` (если используется)
   - Вывод `diagnose.bat`
   - Описание действий перед закрытием

2. Проверьте:
   - Запущенные Python процессы: `tasklist | findstr python`
   - Task Scheduler задачи
   - Автозапуск скрипты

3. Попробуйте:
   - Запуск с правами администратора
   - Временное отключение антивируса
   - Запуск без других Python IDE

## Дополнительные команды для диагностики

### Проверить все Python процессы
```powershell
Get-Process | Where-Object {$_.ProcessName -like "*python*"} | Format-Table Id, ProcessName, StartTime, Path -AutoSize
```

### Проверить автозапуск VoiceDrop
```powershell
Get-Content "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\VoiceDrop.lnk"
```

### Проверить логи событий Windows
```powershell
Get-EventLog -LogName Application -Source "Windows Error Reporting" -Newest 10
```

## Что за продукт
VoiceDrop — десктопное приложение для голосового ввода (диктовки), **локально-приватный
конкурент WhisperFlow**. Захват микрофона по горячей клавише (push-to-talk: зажал —
говоришь, отпустил — транскрибация), распознавание через **ОНЛАЙН ElevenLabs
Speech-to-Text (`scribe_v1`)**, авто-вставка текста в активное окно. На время записи
глушит другие аудио-сессии (pycaw). История записей в SQLite. GUI: системный трей
(pystray) + customtkinter, оверлей записи. Стек: Python, httpx, sounddevice, pynput,
pyperclip, pystray, customtkinter, pycaw, pywin32, python-dotenv.

### Часть 2 — Диагностика реальных проблем (приоритет)
1. **Вылеты/краши.** Приложение иногда вылетает. В `voicedrop.log` (~48k строк,
   обновляется ежедневно) есть реальные доказательства: ~42 `ERROR`, ~26 `Traceback`,
   ~44 `Exception`. Прочитай их, найди корневые причины, предложи фиксы. Добавь
   глобальный обработчик исключений (`sys.excepthook` + `threading.excepthook`) с
   записью крашей в отдельный файл, если его ещё нет.
2. **Сброс микрофона.** Иногда сбрасывается микрофон по умолчанию и переключается на
   другой. Основной — **Microphone (FOX)**, второй — **GrandStream** (с видеокамерой,
   плохой звук, далеко, НЕ использую). В `settings.json` микрофон хранится как
   `microphone_id` + `microphone_name`. ВАЖНО: на Windows один физический FOX виден
   5 раз (MME/DirectSound/WASAPI/WDM-KS), индексы плавают → **сопоставляй устройство
   ПО ИМЕНИ, а не по индексу**, сохраняй точный валидный выбор и НЕ сваливайся молча на
   системный дефолт (это и есть причина переключения на GrandStream). Тот же баг и фикс
   уже разбирали в старом проекте — переиспользуй подход.
3. **Язык (жёсткое требование).** Был баг: говорю по-русски — получаю украинский;
   по-украински — английский. Сейчас в `core/elevenlabs_api.py` язык = `null`
   (автоопределение `scribe_v1`). Нужно: добавить **пиннинг языка** (RU/UK/EN/Авто) в
   настройки и передавать `language_code` в API; идеально обрабатывать RU/UK/EN; не
   допускать «перетекания» языков. Это обязательно должно остаться и быть улучшено.
4. **Грамматика/постобработка** — оценить, можно ли улучшить (опц. «полировка» текста
   через LLM перед вставкой).
